Impor senjata buatan sendiri

Masukkan gambar dan data senjata ke game lokal, lalu berikan ke karakter pilihan Anda.

1. Buat senjata

Maksimal 4096 × 4096 piksel dan 5 MB. Gambar ini menjadi senjata dan ikon Gear.

Seret senjata ke tangan. Tarik bulatan biru untuk memutar atau kotak biru untuk mengubah ukuran. Tombol panah menggeser lebih presisi.

Titik hijau = titik tangan · Model standar game
Titik pegangan pada gambar dan animasi

Klik gagang pada gambar sumber. Penanda merah akan menempel di titik tangan saat X dan Y bernilai 0.

Impor membuat senjata satu tangan dari gambar statis. Gerakan mengikuti animasi karakter. ID diberikan otomatis; katalog lama dicadangkan sebelum diperbarui.

2. Berikan ke karakter

Setelah diberikan, buka ulang game agar katalog baru termuat. Senjata berada di Gear → Weapons.
